BUILD YOUR OPERATING PLAN

A plan for the version of you who may not feel clear.

This builder converts the manual into a local document. Use roles, initials, or plain descriptions — you do not have to enter names or sensitive history.

  • Write short, concrete entries. “Leave the apartment and call M.” beats “make better choices.”
  • Start with the central decision, then the conditions that threaten it. This is an operating document, not a confession.
  • If a section feels too personal, use functional language: “backup person,” “clinic,” “safe public place.”
  • Review it when conditions change — travel, paydays, new supports — while you are clearheaded, not during the hour it protects.
  • Exports are yours to keep safely. Neither file is protected by this website once it leaves the browser.

Private to this browser

The Operating Plan is saved only in this browser using one local storage key: darkRecovery.operatingPlan.v1. It is not submitted, synced, analyzed, or sent to a server.

It is not encrypted. Anyone who can use this browser profile may be able to view it. Clearing browser data may erase it. Exported files become your responsibility.

How to use this page

Autosave keeps a local copy in this browser after edits. Export a text copy for reading and a JSON copy if you want to import the plan later. Use the erase control when you do not want this browser profile to keep the stored plan.
