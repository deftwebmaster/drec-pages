BUILD YOUR OPERATING PLAN

A plan for the version of you who may not feel clear.

This builder converts the manual into a local document. Use roles, initials, or plain descriptions. You do not have to enter names or sensitive history.

The plan should be useful under stress. Write short entries. Prefer concrete actions over ideals. “Leave the apartment and call M.” is stronger than “make better choices.” “No private cash withdrawal during a craving window” is stronger than “be careful with money.” The purpose is to reduce improvisation when the most persuasive argument may be the least safe one.

Start with the central decision. Then add the conditions that threaten it: warning signs, high-risk windows, environmental loopholes, and the functions substance use served. Do not try to write a perfect biography. The plan is an operating document, not a confession.

Review the plan when conditions change: new work hours, travel, paydays, conflict patterns, medication changes handled with a professional, recovery supports added or removed, or a period where safeguards start to feel embarrassing. The plan should change deliberately while you are clearheaded, not privately during the hour it was designed to protect.

If a section feels too personal, use functional language. “First person,” “backup person,” “clinic,” “safe public place,” or “the route away from access” may be enough. The plan belongs to the reader using it, not to an audience. It should contain the least sensitive wording that still interrupts danger.

After exporting, keep files only where you are comfortable keeping them. A text export is easy to read and print. A JSON export is useful for importing later. Neither file is protected by this website after it leaves the browser.

Private to this browser

The Operating Plan is saved only in this browser using one local storage key: darkRecovery.operatingPlan.v1. It is not submitted, synced, analyzed, or sent to a server.

It is not encrypted. Anyone who can use this browser profile may be able to view it. Clearing browser data may erase it. Exported files become your responsibility.

How to use this page

Autosave keeps a local copy in this browser after edits. Export a text copy for reading and a JSON copy if you want to import the plan later. Use the erase control when you do not want this browser profile to keep the stored plan.
